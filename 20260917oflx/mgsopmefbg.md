# 孕中期的孕妇可以吃小河虾吗

> 更新时间：2026-09-17 (UTC+8)

虾的肉质鲜美，蛋白质丰富，是人们非常喜爱的一种食物。孕妇适当地吃虾可以补充蛋白质和钙，促进胎儿健康发育。虾的种类有很多，内陆地区比较常见的是河虾。与海虾相比，河虾的个头比较小，肉质更细嫩。那么，孕中期的孕妇可以吃小河虾吗?
孕中期的孕妇可以吃小河虾吗
　　孕中期的孕妇可以吃小河虾。小河虾是一种高蛋白、低脂肪的食物，孕妇适当食用河虾，降低胆固醇含量，保护心血管系统。河虾富含钙，能促进孕妇补钙，对胎儿的大脑和智力发育有益。哺乳期的母亲也可以吃河虾，还具有通奶功能，营养丰富。河虾也能增强大脑，适当地吃一些河虾对身体的恢复和营养补充非常有益。

　　在孕期吃小河虾的时候，必须选用新鲜的，应该购买体形弯曲，虾头虾尾完整的，同时要注意虾的颜色，尤其是虾头部位要有发黑的现象，这就说明不新鲜了。孕妇吃了这类虾，就容易导致腹泻、腹痛，所以在选用河虾的时候，尽量选择新鲜的河虾。

　　如果是新鲜的虾，虾壳和虾肉的连接是非常紧密，大家在剥虾壳的时候，要用些力气才可以剥掉。而且在将虾壳剥掉后，会感觉虾肉有一些黏手。另外，新鲜小河虾没有任何异味，如果大家闻到有腥臭味的话，就证明不新鲜了，大家不要购买这类小河虾。

　　爱吃河虾的孕妇们是可以食用的，但是在生活中一定要注意食用河虾的量，还有一点就是河虾的吃法有很多，不管是哪一种河虾的做法都可以发挥出河虾的营养价值，所以人们可以换着方法做着吃，从而获取多方面营养。
小河虾的作用与功效
　　1. 补充营养：小河虾营养价值不低，其中含有丰富优质蛋白质、以及钙、镁、钾等多种矿物质，均属于人体必需的营养成分，食用可以为身体补充所需营养素，维持人体正常的生理功能，利于身体健康。

　　2. 通乳汁：如果妇女产后乳汁少或无乳汁，鲜虾肉500克，研碎，黄酒热服， 每日3次，连服几日，可起催乳作用。

　　3. 缓解神经衰弱：虾皮有镇静作用，常用来治疗神经衰弱，植物神经功能紊 乱诸症。海虾是可以为大脑提供营养的美味食品。海虾中含有三种重要的脂肪酸， 能使人长时间保持精力集中。

　　4. 促进生长：小河虾含有不少优质蛋白质，而蛋白质是构成白血球和抗体的主要物质，适量食用有利于维持自身的免疫功能，可以促进神经、血管、大脑细胞的活性以及发育生长，另外，其中丰富的钙、镁、磷元素可以促进骨骼的合成，具有促进身体生长发育的作用。
